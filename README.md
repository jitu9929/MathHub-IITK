# MathHub IITK

This website is structured exactly as:

MathHub IITK
→ Semester 1 / 2 / 3 / 4
→ Academic Year (for example 2026, 2025, 2024)
→ PYQs + Notes
→ Open PDF/resource

## How to use
Open `index.html` in a browser.

### Add a year
Open **Admin** → choose semester → enter year → Add Year.

### Add PYQ or Notes
Open a semester → open a year → choose **Add PYQ** or **Add Notes** → enter title and paste a public PDF/file URL.

### Important
This is a front-end version. Data is stored in the browser. The Admin area is not secure and does not upload files itself.
